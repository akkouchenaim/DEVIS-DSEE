# DSEE Devis — fiches appareils

Les fiches sont définies séparément dans `appareils/flash_ea_1112.py` et `appareils/parr_6200.py`. Elles sont importées automatiquement dans `app.py` et proposées dans le catalogue.

Ajoutez vos propres photos dans `images/flash_ea_1112.jpg` et `images/parr_6200.jpg` (aucune photo n’est fournie). Vous pouvez également téléverser une photo depuis l’interface.

Installation : `pip install -r requirements.txt`
Lancement : `streamlit run app.py`

**Attention :** les temps et coûts préremplis sont indicatifs. Vérifiez-les selon les protocoles et tarifs DSEE. Les modifications en session ne sont pas automatiquement persistées ; utilisez l’export JSON.
